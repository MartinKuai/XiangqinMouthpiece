# Style Guide - 相亲嘴替语言风格

## 核心风格

**低门槛、短反转、轻冒犯、别装。**

这不是传统"温柔高情商"，而是：
- 表面平静
- 实际反客为主
- 不脏不骂
- 有点损
- 有边界
- 1 秒内能看懂笑点
- 冒犯的是对方这句话，而不是攻击对方这个人

## 允许使用的风格

- 谐音梗
- 双关梗
- 反向理解
- 生活常识类比
- 基础数学梗（绝对值、等号、不等号、加减分、及格线、满分）
- 极简符号梗
- 日常场景类比：售后、质检、面试、打折、排队、过期、会员、清仓、说明书

## 谨慎使用

- 404
- bug
- 系统提示

## 默认不要使用

- SQL
- 复杂代码
- 高阶数学
- 微积分
- 集合论
- 复杂物理化学
- 只有程序员才懂的黑话
- 任何显得"死装"的表达

## 重点说明

保留类似"绝对值"这种大众能理解的符号错位感。

例如：
- 对方说"你这手机买得不值啊"
- 可以理解为抓住"不值 / 值"
- 生成类似"绝对值"式冷幽默
- 但不要扩展成过度程序员化或学术化的梗

## 四种回复风格

### A. 真发版
- 适合真实聊天
- 不撕破脸
- 有边界但温和

### B. 阴阳版
- 有边界、有锋芒
- 不骂人
- 让对方意识到问题

### C. 日常脑回路错位版
- 低门槛的谐音、双关
- 生活常识、基础数学
- 反向理解完成反转

### D. 抽象整活版
- 适合截图娱乐
- 不建议真实发送
- 可以更夸张

## 示例对比

**输入**: "你工资多少？"

**真发版**: "这个属于个人隐私，不太方便说呢。"
**阴阳版**: "你先说你的，我看看要不要继续聊。"
**脑回路错位版**: "工资就像头发，看着多，实际没多少。"
**抽象整活版**: "工资？我月薪三千，但快乐无价。"
